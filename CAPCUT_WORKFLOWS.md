# CapCut Desktop workflow inventory

Reference checked **November 21, 2026** using CapCut’s public English-language product pages, Help Center, and tutorials. The scope includes workflows described for the Windows/macOS desktop editor and related services with a documented desktop entry or handoff. Menu labels and availability can change by build, region, account, hardware, and project contents. Feature flags, individual assets, and exact entitlements remain subject to verification in the installed editor. See [setup artifact evidence](SETUP_EVIDENCE.md) for the REA inspection. ## Reading the access and coverage notes

- **Free** means a source specifically describes the workflow as free, or identifies it as part of the basic editing set. Individual catalog items may still be premium. **Pro documented** means a CapCut pricing or support page identifies Pro access for that capability. **Varies** flags limited use, credits, rollout, or conflicting sources. **Unstated** means the desktop workflow is documented and its exact entitlement is unresolved in the cited sources. Continuing free access requires workflow-specific evidence. [Pricing](https://www.capcut.com/pricing) · [Free and Pro guide](https://www.capcut.com/resource/capcut-standard-vs-pro) · [Credit rules](https://www.capcut.com/clause/credits-rule)
- CapCut’s pricing page lists Free, Pro, Ultra, and Teams. The Help Center also describes a **Standard subscription** aimed primarily at mobile and identifies Pro as the route to paid membership features on PC. The term “Standard” in some comparison articles also refers to free basics. The catalog uses **Free** for the no-cost desktop tier. [Pricing](https://www.capcut.com/pricing) · [Standard device eligibility](https://www.capcut.com/help/valid-devices-for-standard-subscription) · [Standard and Pro Help](https://www.capcut.com/help/capcut-standard-vs-pro)
- **CutAd** refers to the current workspace. **Available** indicates the core workflow exists, **Partial** identifies a narrower workflow, and **Open** means the workflow is outside the recorded baseline. [CutAd workflow coverage](FEATURES.md) reports Linux integration tests and Windows integration tests under Wine for core media/edit/export and records the specific coverage for other implemented workflows. The beta release workflow runs Linux and native Windows package smoke tests.
