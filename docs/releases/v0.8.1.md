## CutAd 0.8.1

CutAd is an independent Rust desktop editor for Linux and Windows. This release adds visual clip fades and makes transitions respect them in preview and export.

- Fade video, image, and text clips in and out from the **Animation** inspector. **Fade both** applies up to half a second at each end, and fades survive splits, trims, scrubbing, and export.
- Cut transitions now honor an incoming clip's fade-in, so the outgoing shot remains visible through the blend instead of the incoming clip appearing at full opacity.
- Keep the existing project-scoped MCP controls, SRT captions, masks, position keyframes, and offline exports for MP4, WebM, lossless MKV, stereo WAV, and PNG stills.

Download the ZIP for Windows or the tar.gz for Linux. Extract the archive and run CutAd. Install FFmpeg 8 or later with drawtext for media workflows. `SHA256SUMS` verifies the downloads. Build, test, and packaging details are in the README.
