## CutAd 0.7.1

CutAd is an independent Rust desktop editor for Linux and Windows. This release brings the native editing workflows and project-scoped MCP controls together.

- Connect Codex, Claude Code, OpenCode, Kilo Code, or Antigravity using `cutad --mcp-config CLIENT PROJECT`. MCP starts in read-only mode. Add `--write` to enable title insertion, clip splitting, gain changes, and export.
- Edit with rectangle, ellipse, and linear masks, audio fades, timeline waveforms, and position keyframes.
- Import and export SRT. Optional local `whisper-cli` and a compatible model generate editable captions from the timeline audio.
- Export MP4, WebM, lossless MKV, stereo WAV, or a full-resolution PNG still.

Download the ZIP for Windows or the tar.gz for Linux. Extract the archive and run CutAd. Install FFmpeg 8 or later with drawtext for media workflows. `SHA256SUMS` verifies the downloads. Build, test, and packaging details are in the README.
