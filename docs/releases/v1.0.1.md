## Faster rendering

- Exports start decoding near each cut for supported source footage. Audio stays aligned and exports keep the existing encoding settings.
- Freeze frames are resized once before being repeated. Desktop exports also pause preview playback to free resources.

| Sample MP4 export | 1.0.0 | 1.0.1 |
| --- | ---: | ---: |
| Eight-cut 1080p edit | 28.5 s | 10.2 s |
| Freeze-frame edit | 6.2 s | 1.3 s |

Both sample exports produced byte-identical files. Render times depend on the footage, edit, and hardware.

## Downloads

Extract the Windows x86-64 ZIP or Linux x86-64 tarball and run the included executable. FFmpeg 8 or newer is required for media preview and export. Use the attached `SHA256SUMS` file to verify the archives.
