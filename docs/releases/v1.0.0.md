## What’s new

- Assemble multicamera edits from up to nine clips. Sync by matching source audio or by marking a shared cue, choose angles at the playhead, and keep a continuous reference audio track.
- Paint erase and restore masks in Preview. Every stroke is undoable and follows the clip’s transform in the export.
- Create 8-bit SDR video proxies for reduced-resolution playback. Full-resolution preview, audio, and exports use the source media.
- Save a portable copy with source media and color LUTs collected into one folder.
- Since 0.8.1, CutAd also gained clip grouping, named and detected beat markers, editable transform and gain keyframes, reverse and optical flow, voiceover, bilingual captions, local background removal and reframing, autosave recovery, and range export.

## Supported workflows

CutAd 1.0.0 is a stable release of the independent, open-source editor. Compound clips, editable speed ramps, full-motion multicamera monitoring, advanced AI editing, and cloud collaboration are still outside this release. CapCut’s paid effect and template catalogs and hosted AI services require access through CapCut. See the [workflow inventory](https://github.com/ArthurSimin/CutAd/blob/v1.0.0/CAPCUT_WORKFLOWS.md) for details.

## Downloads

Extract the Windows x86-64 ZIP or Linux x86-64 tarball and run the included executable. Install FFmpeg 8 or newer for media preview and export. Offline speech and subject tools use separately installed runtimes and compatible models. Use the attached `SHA256SUMS` file to verify the archives.
