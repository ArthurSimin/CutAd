# CutAd assets

CutAd's logo is covered by the project's MIT license. The drawing source is `source/logo.mvg`.

Reproduce the PNG with ImageMagick from the repository root:

```sh
magick -size 256x256 xc:none -draw '@assets/source/logo.mvg' PNG32:assets/logo.png
```
