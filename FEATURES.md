# CutAd desktop workflow coverage

Reference checked November 22, 2026. CapCut documents both desktop editing tools and subscription features across multiple products. The table tracks the documented workflows against the current CutAd workspace. [CapCut desktop editor](https://www.capcut.com/resource/pc-professional-video-editor) · [Editing guide](https://www.capcut.com/resource/how-to-use-capcut) · [Pro features](https://www.capcut.com/help/capcut-standard-vs-pro)

| Workflow | CutAd workspace | Verification |
| --- | --- | --- |
| Local media, multitrack editing, and export | Import video, stills, and audio. Split, trim, move, duplicate, detach audio, undo and redo, save and reopen. Export MP4, WebM, or lossless MKV at 24, 30, 60, or 120 fps. New timelines can match first-video dimensions up to a 4096-pixel edge. | Linux integration tests and Windows integration tests under Wine. |
| Playhead preview and live controls | Optional reduced-resolution proxies leave full-quality preview, audio, and export on the source media. Auto uses responsive scrubbing and playback with full-canvas stills. Full, half, and quarter preview modes are available. Cached scrubbing and short buffered playback bound the work. Text, transform, color, and gain edits apply immediately. Decode and compositing time still depend on footage and effects. | Integration tests compare partial previews against full renders. |
| Text, fonts, and stickers | Seven editable title styles with optional background boxes, typography controls, system fonts, local font imports, DaFont categories and direct URL installs, curated open fonts, and local still-image overlays. | Title and font import tests, plus preview and export checks. |
| Effects and transitions | 42 independently defined color, lens, motion, texture, and audio presets, eight cut transitions, clip transforms, and audio gain. Some editing workflows such as preset effects use an apply action. | Integration render tests. |
| Color correction and green-screen removal | Live brightness, contrast, saturation, and custom chroma color, tolerance, and softness. | Tests verify the keyed layer and grading in the shared preview and export renderer. |
| Templates and draft interchange | Reusable CutAd templates and import of supported local, readable CapCut draft JSON. Missing media becomes replaceable slots. Hosted template catalogs and unsupported draft settings require other workflows. | Generated draft fixtures and project round-trip tests. |
| Animation and finishing | Editable X/Y position keyframes animate video, images, and text. Video, image, and text clips fade in and out under **Animation**; fades survive splitting, trimming, scrubbing, and export. Scale, rotation, and opacity also have editable keyframes. Blend modes and optical flow are listed below. Rectangle, ellipse, and linear clip masks support feathering and inversion. Erase and restore brushes refine masks in Preview. | Position interpolation, visual fade, transition, split, project reopen, preview, and export tests. [CapCut keyframe workflow](https://www.capcut.com/resource/how-to-add-keyframes-in-capcut) |
| Captions, tracking, and audio cleanup | SRT import and export support editable captions. Offline automatic captions use local whisper.cpp and a compatible model. Video background removal and overlay tracking are covered below. | SRT timecodes, overlaps, and project round-trip tests. [CapCut subtitle workflow](https://www.capcut.com/help/how-to-import-subtitles) |
| Source quality | Full-canvas 4:4:4 stills and a lossless FFV1/FLAC master of the rendered edit. The editor composites 8-bit SDR at the canvas dimensions and uses a 48 kHz stereo mix. HDR and unrestricted native frame rates remain open. | Tests compare adjacent 60 fps source frames and verify pixel equality on a same-size, unedited 4:4:4 sample. |
| Audio and still exports | Timeline waveforms, clip gain and fades, stereo WAV export, and full-canvas PNG export at the playhead. | Linux and Windows build checks with generated media. |
| Hosted media and collaboration | Commercial asset catalogs, generative media, shared projects, brand libraries, and team review are separate service workflows. | Pending implementation. |

## In development

| Workflow | Implementation | Verification |
| --- | --- | --- |
| Portable project copies | Gather local source media and LUTs into a moveable project folder. | Project reopen from a different directory, shared-file deduplication, and cancellation cleanup. |
| Multicamera edits | Align marked source points, preview angle thumbnails at the playhead, compile angle switches into editable clips, and keep reference audio continuous. | Linux export checked before, during, and after an angle switch. |
| Audio synchronization | Align selected clips on separate tracks by matching their source audio. | Generated recordings with gain and trim differences, signed offsets, and rejected overlapping moves. |
| Clip groups | Multi-select timeline clips, group them, and drag any member while preserving offsets and compatible track placement. | Desktop drag with saved offsets, rejected overlap and track moves, and project reopen. |
| Export title and cover | Write title metadata into MP4, WebM, or Matroska and embed a chosen timeline frame as an MP4 cover. | FFprobe verified the attached picture, title, video duration, and audio stream. |
| Draft recovery and recent projects | Back up unsaved changes locally while editing, recover after an unexpected exit, and reopen recent saved projects. Running windows hold exclusive recovery locks. | Project media paths, concurrent recovery access, and recent ordering checked with isolated files. |
| Position easing and slide presets | Linear, ease in, ease out, ease in out, and hold interpolation. Left and right slide presets create editable keyframes. | Linux position, scrub, and split tests. |
| Crop and mirror | Independent edge percentages and horizontal and vertical flips for video and stills. | Linux project round trip and preview/export comparison. |
| Freeze frame | Insert a silent three-second hold at the playhead and shift subsequent clips on the same track. | Linux source-frame and resume timing test. |
| Automatic scene detection | Scan the selected source range for hard cuts and split the clip at those boundaries in a single undoable edit. | Linux tests on synthetic hard cuts and trimmed source ranges. |
| Range export | Render the whole edit, the selected clip’s time range, or custom In and Out times. | Linux duration, first-frame, and invalid-range tests. |
| Constant clip speed and audio pitch | Retiming from 0.25× to 4× with pitch preservation, same-track ripple, and fractional source timing. Independent pitch adjustment from −12 to +12 semitones. | Linux tests for frame timing, split and reopen, source-duration round trip, and measured pitch. Optical flow can generate an intermediate 120 fps source for retiming. |
| Blend modes and opacity keyframes | Multiply, Screen, Darken, Lighten, Difference, and Add. Opacity keyframes interpolate independently of position, with masks and edge fades still applied. | Linux compositing, scrub, export, and split tests. |
| Local color LUTs | Apply and remove a local 3D `.cube` LUT, with project-relative paths when the LUT is in the project folder. | Linux preview, export, reopen, and source protection tests. |
| Additional audio delivery formats | Export the stereo timeline mix as lossless FLAC or 320 kbps MP3 from the desktop, command line, or MCP. | Codec, channel, duration, and mix verification with generated audio. |
| Animated GIF delivery and stickers | Export a looping animation of the entire edit or a selected timeline range at 12, 15, 24, or 30 fps. Import GIF animations on a sticker track. | Generated GIF range, loop metadata, and reimport tests. |
| Ripple delete | Remove a clip and shift later clips on the same track by the removed duration. | Timeline positions and source offsets verified in a multitrack fixture. |
| Side-by-side review and vertical reveal | Original editable templates with replaceable media slots, titles, and a reveal transition. | Slot replacement, saved-project reopen, and rendered preview tests. |
| Rotation, scale, and opacity curves | Independent keyframes with linear, eased, or hold interpolation for all three controls, alongside position keyframes. | Preview and lossless export match after animated transforms, splits, and reopen. |
| Loudness and stereo controls | Normalize the selected clip toward −16 LUFS, with gain and peak limits. Balance stereo sound, mix to mono, or route either source channel to both outputs. | Loudness measured from a finished WAV and channel samples checked against a generated fixture. |
| Automatic color and reference tone | Analyze a source frame locally and generate editable brightness, contrast, and saturation values. Optionally use a reference frame as the target. | Synthetic dark footage and reference tones checked in preview and lossless export. |
| Per-color grading | Adjust hue, saturation, and intensity for red, yellow, green, cyan, blue, or magenta before applying a LUT. | Selective recoloring checked after reopen in preview and export. |
| Copy and paste clip settings | Copy visual or audio settings from the clip menu and paste compatible settings onto another clip. | Timeline, source, and audio preservation tested when pasting visual settings. |
| Reverse clip | Save reversed picture and sound from the selected source span in a separate Matroska file. The current clip keeps its timing and settings. | Trimmed source, chunk boundaries, canceled processing, and project reopen checked with generated footage. |
| Transcript search and export | Search visible caption clips, jump to them for text edits, or export plain text. | Case-insensitive search, timeline order, and text export checked against an editable caption fixture. |
| Timeline markers | Add, rename, remove, and jump to named time markers. Editing snaps to marker positions when snapping is enabled. | Marker ordering, renaming, and project reopen checked. |
| Voiceover from a microphone | Select the input, optionally play the timeline while capturing, and save a local WAV at the original playhead on an available audio track. | Linux desktop recorded generated audio through an isolated virtual input and saved the take at the selected frame. |
| Automatic beat markers | Detect recurring pulses in the selected audio and add named timeline markers that work with snapping. | Generated tempo, trimmed source timing, timeline offset, and a sustained-tone control. |
| Audio gain keyframes | Animate gain between timeline frames with reusable easing and edit the same keyframes through MCP. | Verified split and reopen, sample-level gain in full and range renders, and MCP frame validation. |
| Motion interpolation and stabilization | Generate a motion-interpolated 120 fps copy for slow playback, or stabilize camera shake. Both work locally on supported opaque 8-bit footage. | Generated frames, audio samples, frame timing, and shake reduction checked against synthetic footage. |
| Overlay motion tracking | Track a visible patch in footage beneath an overlay and create editable X/Y position keyframes. | Generated moving target, displacement, cancellation, and project reopen checked. |
| Offline background removal | Generate a transparent PNG or FFV1/FLAC video from a timeline clip using a local U²-Net model. | Local model test checks video and still alpha, the selected span, source audio, final compositing, and cancellation. |
| Automatically reframe foreground | Fill the current canvas and keep the detected foreground in view with editable position keyframes. | A real-photo fixture moving across generated footage verifies subject position and the visible result. |

The position, framing, scene detection, freeze, range, retiming, pitch, blend, opacity, rotation, scale, LUT, color-range, loudness, stereo routing, clip-settings, reverse, transcript, marker, stabilization, motion interpolation, and overlay tracking tests also pass with the Windows build and Windows FFmpeg under Wine.
